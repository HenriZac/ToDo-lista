# Tehtävälista

Tämä on pythonilla tehty tehtävälistasovellus.
Ohjelmalla voi esimerkiksi lisätä, muokata, poistaa tehtäviä ja merkitä niitä tehdyksi.
Tehtäville voi määrittää prioriteetin (Matala, normaali, korkea) ja määräpäivän.
Lopuksi tehtävät tallennetaan JSON-tiedostoon ja muutokset kirjataan lokiin.

## Järjestelmävaatimukset

- Python 3
- Toimii Linuxissa

Ohjelman käynnistys tapahtuu komennolla: python3 main.py

## Siirrettävyys

Ohjelma toimii toisella tietokoneella, kun Python 3 on asennettuna.
Kaikki ohjelman Python-tiedostot tulee olla samassa kansiossa.

## Rajoitteet

- Ohjelmaa käytetään Linuxin terminaalissa.
- Tehtävät tallennetaan paikallisesti JSON-tiedostoon.
- Ohjelmassa ei ole graafista käyttöliittymää, vaan kaikki tapahtuu terminaalissa.
- Tehtävät ei synkronoidu eri laitteiden välillä
